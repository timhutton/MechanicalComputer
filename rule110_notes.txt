Rule 110:

ABC ABC ABC ABC ABC ABC ABC ABC
111 110 101 100 011 010 001 000
 0   1   1   0   1   1   1   0

= (B XOR C) OR (notA AND B)

Many other expressions are possible.

Input and output rods have positions in [0,1].
One rod pushes another: b = max(a, b)  [0 gears]
One rod pulls another: b = min(a, b)   [0 gears]
An anchored gear between two rods: b = 1 - a    [1 gear]
A double gear with two rods on the same side: b = 2a    [1 gear with 2 radii]
(or any fixed multiplier)
Double rack with a pinion mounted on rod c: c = (a + b) / 2   [1 gear]
Adding/subtracting a fixed value is free, just affects a rod's length.

Chain:

not_a = 1 - a
not_b = 1 - b
not_c = 1 - c
f = (c + not_b) / 2
g = f * 2 - 1 = c + not_b - 1 (using gear E)
h = -g (using the opposite side of gear E)
output1 = min(min(c, not_b), g)  # pushed forward by g, pulled back by c and not_b = c AND not_b
output2 = min(min(not_c, b), h)  # pushed forward by h, pulled back by not_c and b = not_c AND b
m = (b + not_a) / 2
p = m * 2 - 1 (using gear N)
j = (output1 + output2) / 2
output3 = j * 2 = b XOR c (using gear K)
output4 = min(min(b, not_a), p)  # pushed forward by p, pulled back by b and not_a = not_a AND b
q = (output3 + output4) / 2 (q is the gear, r is the rod)
t = q * 2 (using gear S)
output5 = min(max(output3, output4), t)  # pulled back by t, pushed forward by output3 and ouput4
        = (b XOR c) OR (not_a AND b) = rule110
